# منجِز: دليل التشغيل

تطبيق مهام عربي لأندرويد وآيفون من كود واحد. التنبيهات تصل في موعدها حتى والتطبيق مغلق، والمهام المنجزة تنتقل إلى أرشيف أسبوعي ولا تُحذف.

## ما تحتاجه
- **Node.js** (نسخة LTS) من nodejs.org
- **أندرويد:** برنامج Android Studio
- **آيفون:** جهاز Mac وبرنامج Xcode وحساب Apple (المجاني يكفي للتجربة على جهازك، لكن التطبيق ينتهي بعد 7 أيام ويُعاد تثبيته)

## تشغيل أندرويد
افتح الطرفية (Terminal) داخل مجلد المشروع ثم نفّذ:

```
npm install
npm run setup
npm run android
```

1. الأمر الثاني يضيف منصة أندرويد ويولّد الأيقونات ويضبط الصلاحيات.
2. الأمر الثالث يفتح Android Studio، وصِل هاتفك بكابل (مع تفعيل «تصحيح USB») ثم اضغط زر **Run**.
3. لملف تثبيت جاهز: من القائمة Build ثم Build APK(s).

## تشغيل آيفون (على Mac)
```
npm install
npm run setup:ios
npm run ios
```
في Xcode اختر فريقك من Signing & Capabilities، واختر جهازك، ثم اضغط Run.

## أول تشغيل
1. اسمح بالإشعارات عند طلبها.
2. من الإعدادات في التطبيق (أيقونة الترس) فعّل **المنبّهات الدقيقة** على أندرويد.
3. اضغط **تجربة تنبيه بعد 5 ثوانٍ**، ثم أغلق التطبيق وانتظر. إذا وصل التنبيه فكل شيء يعمل.
4. على بعض هواتف سامسونج وشاومي وهواوي: اجعل التطبيق «بدون قيود» في إعدادات البطارية حتى لا يوقف النظام التنبيهات.

## تعديل التطبيق مع بقاء بياناتك
كل ملفات التطبيق في مجلد `www`:
- `index.html` الهيكل والنوافذ
- `css/app.css` الألوان والخلفيات (في أول الملف)
- `js/app.js` المنطق

بعد أي تعديل نفّذ `npm run sync` ثم اضغط Run من Android Studio أو Xcode. التحديث يُثبَّت فوق النسخة القديمة وتبقى مهامك كما هي.

لتبقى البيانات سليمة:
- **لا تحذف التطبيق من الهاتف**، لأن حذفه يمسح بياناته.
- لا تغيّر `appId` في `capacitor.config.json` (وهو `com.munjiz.tasks`).
- على أندرويد، إن بنيت نسخة موقّعة بمفتاح مختلف فسيطلب النظام حذف القديمة أولاً. احتفظ بنفس المفتاح.
- احفظ نسخة احتياطية من الإعدادات (**حفظ نسخة احتياطية**) قبل أي تغيير كبير. تُحفظ كملف يمكنك إرساله لنفسك، وتُستعاد من نفس الشاشة.

يمكنك أيضاً أن ترسل لي الملفات وتطلب التعديل، وأعيد لك ملفات `www` المحدّثة لتنسخها فوق القديمة.

## حدود يجب معرفتها
- **آيفون:** لا يسمح النظام لتطبيق عادي بمنبّه يرنّ بلا توقف مثل تطبيق الساعة. التنبيه يصل بإشعار وصوت، وقد يُكتم إذا كان الهاتف في وضع «عدم الإزعاج» أو التركيز. وللآيفون حد أقصى 64 تنبيهاً مجدولاً، والتطبيق يجدول الأقرب موعداً أولاً.
- **أندرويد:** يصل التنبيه بصوت وإشعار عالي الأهمية. للمواعيد الحرجة جداً استخدم تطبيق الساعة إلى جانبه.
- **المزامنة:** المهام محفوظة على الهاتف فقط. لنقلها إلى هاتف آخر استخدم النسخة الاحتياطية.
- **الخطوط:** يستخدم التطبيق خط النظام العربي في الهاتف، فيعمل دون إنترنت.

## الميزات الجديدة وكيف تعمل

- **التكرار**: عند إنجاز مهمة متكررة (يومياً/أسبوعياً/شهرياً) تُنشأ تلقائياً المهمة التالية. يتطلب التكرار تحديد موعد.
- **أزرار الإشعار**: في الإشعار زران «تم الإنجاز» و«غفوة 10 دقائق». على أندرويد تظهر عند سحب الإشعار للأسفل، وعلى آيفون بالضغط المطوّل عليه. الضغط على أي زر يفتح التطبيق لينفّذ الإجراء.
- **التراجع**: بعد أي إنجاز يظهر شريط «تراجع / ملاحظة» لمدة 7 ثوانٍ. يمكن إيقاف الإنجاز السريع من الإعدادات.
- **البحث**: أيقونة العدسة. يبحث في العناوين والملاحظات والتصنيفات والخطوات الفرعية، ويشمل المنجزة.
- **الخطوات الفرعية والأولوية** تُضبط من نافذة المهمة. الأولوية تحدد الترتيب داخل كل قسم.
- **الإحصائيات**: تبويب مستقل، آخر 7 أو 30 يوماً.
- **القفل**: الإعدادات ← قفل التطبيق (رمز من 4 أرقام). يُطلب عند الفتح وبعد غياب نحو 20 ثانية. **لا يمكن استعادة الرمز إن نسيته** إلا بحذف التطبيق (وتُحذف بياناته)، فاحفظ نسخة احتياطية أولاً.
- **الفتح بالبصمة/الوجه (اختياري)**: بعد `npm install` نفّذ مرة واحدة:
  `npm install @aparajita/capacitor-biometric-auth` ثم `npm run sync`. إن لم تثبّتها يعمل القفل بالرمز فقط، وهذا الجزء لم أستطع تجربته على جهاز حقيقي.
- **الاهتزاز**: يحتاج `@capacitor/haptics` (مضافة في package.json وتُثبّت تلقائياً).

بعد التحديث نفّذ: `npm install` ثم `npm run sync` (وعلى آيفون `npm run setup:ios` مرة واحدة لإضافة وصف Face ID).
